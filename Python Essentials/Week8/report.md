This project is meant to act as a simple patient registry system for a local clinic. The code allows the user to add, view, list, and discharge patients using a simple menu system. This project helped me understand how real programs handle data storage, why error handling and validation is important, and how dictionaries and lists can work together to organize information better than seperately. Implementing features like auto-generated IDs and discharge status gave me a stronger understanding of problem-solving and how each part of a program supports the others. Overall, I believe this project improved my confidence in writing functional, user-friendly Python applications.
